# VOLLEYVERSE 🏐

**Rise. Compete. Become a Legend.**

VOLLEYVERSE is a mobile-friendly 3D volleyball game prototype built for the web.

## Current prototype
- 3D indoor volleyball court
- 6 players per side
- Mobile joystick controls
- Pass, Set, Spike, Block, Dive and Serve buttons
- Ball physics and net collision
- Volleyball scoring with sets
- Best-of-5 match structure
- Responsive HUD and VOLLEYVERSE visual style

## Planned roadmap
1. Character roster, positions, stats and rarity
2. Better volleyball AI and realistic animations
3. Career, Training and Ranked modes
4. Team management and chemistry
5. Online multiplayer, accounts and cloud saves
6. Cosmetics, gems, seasons, events and Battle Pass
7. Clubs, World Championship, leaderboards and replays

## Run
Open `index.html` in a modern browser. The project uses Three.js from a CDN.
